## 本轮落实的内容

- 将上传内容按“主 Skill + 模块四”拼接；保留探究、误区、分层与心理安全；取消门禁数值副本，区分机器、浏览器、教师三类验收。
- 范式矩阵独立存放，HTML 阶段只加载已确认册次的一行。册次不明不硬推范式；教师设想在离线与门禁契约内优先。
- 文稿阶段仍使用模块一至三和原有用户提示词；HTML 阶段不再加载 Word/Marp 排版规则、公共 CSS 或全册范式。
- AI 输出本课 DOM、专属 CSS、仿真状态/判据、测验内容和教师说明；程序维护 CSS、导航、进度、提示、重置、徽章、自评、评分、凭单与奖状。
- 复用原 base-template 的视觉样式，重写其中不符合新契约的公共交互。仿真采用 Shadow DOM 隔离专属 CSS；它不是不可信脚本安全沙箱。
- 统一测验 q/options/correct/why；先选后判、未答零分、首次正式整数百分制成绩不被实验重置改写。
- 独立、带完整示范完成和累计成就分别记录；可导航、回看、求助和暂时跳过；求助或自评不授知识徽章。
- 固定凭单表头与第二行五列、无 BOM、身份选填与字段清理，下载和查看/复制使用同一文本；奖状人人能开，称号不虚称达标，支持 Esc 与焦点返回。
- 导语、目标、基础/进阶判据共同计入 data-prose 正文；不通过挪文字、删屏、补标记来通过检查。
- 使用全部三件文稿作为上下文，每个 V2 探究屏的 sourceTask 必须在三件文稿中共同出现；不另造主任务名。
- V2 先做 JSON、接口、数值、JS 语法、文档完整性和现有脚本门禁，再通过临时文件原子替换 HTML；失败不运行 V1 修正器、不重试、不替换已有 HTML。门禁不可用也拒绝发布。
- 教师 3—5 行说明单独写 TXT，V2 资料包附带该文件，不进入学生 HTML 或 Word 编译路径。

- 未调用真实付费模型；不存在成功率、Token 节省、耗时提升或课堂时长的量化结论。
