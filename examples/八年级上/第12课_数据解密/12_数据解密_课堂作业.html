🔍 第一步 · 算法分析

看懂数据解密的四个步骤

任务情境：间谍发出密令 KHOOR，每个字母都按字母表往后挪了 3 位。解密是加密的逆过程：拿密文、取密钥、逆运算、还原文。先看懂这四步，再去动手破译。

🔒 加密（往后加）

明文字母序号 + 密钥

HELLO，密钥 3 → KHOOR

🔓 解密（往前减）

密文字母序号 − 密钥

KHOOR，密钥 3 → HELLO

⚠️ 越界口诀：字母表到头就绕回开头（Z 用密钥 3 加密 → C）。程序里用"对 26 取余"实现。

🛠️ 任务三 · 逻辑排雷

找出解密程序中的 3 处逻辑 bug

排雷任务：这段解密程序藏着 3 处逻辑错误——加减方向写反、越界未取余、大小写丢失。逐个诊断，选择正确的修复方案。
💥 故障一：解密结果比密文"更乱"
n = 字母序号(ch) + key  # 解密步骤
💥 故障二：解密字母 Z 时程序崩溃
n = 序号(ch) - key  # ch='C', key=5 时 n=-2，无对应字母
💥 故障三：解密出的明文大小写全丢了
plain = plain + 序号转字母(n).lower()  # 强制转小写
