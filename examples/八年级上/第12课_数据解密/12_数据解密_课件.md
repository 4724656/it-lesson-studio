# 第12课 数据解密

## 从一封神秘密信，追踪密钥与算法

<div class="callout">今天的主线：密钥探秘 → 变量追踪 → 逻辑排雷</div>

---

# 一封密信，藏着什么？

<div class="grid-2">
<div class="card card-warm">
<h3>密文</h3>
<ul>
<li><code>KHOOR</code></li>
<li>字母看起来有规律地“挪了位置”</li>
</ul>
</div>
<div class="card card-highlight">
<h3>破译线索</h3>
<ul>
<li>假设加密时向后移动3格</li>
<li>解密时，沿字母表反向移动</li>
</ul>
</div>
</div>

<div class="callout">先猜一猜：每个字母向前退3格，会得到什么？</div>

---

# 任务一：密钥探秘

<div class="grid-2">
<div class="card card-highlight">
<h3>上机操作</h3>
<ul>
<li>打开凯撒密码移位轮盘</li>
<li>拖动滑块：<code>Key = 1~25</code></li>
<li>观察密文与明文如何对应</li>
</ul>
</div>
<div class="card">
<h3>完成标准</h3>
<ul>
<li>用密钥3还原 <code>KHOOR</code></li>
<li>说清解密移动方向</li>
<li>改变密钥，观察输出变化</li>
</ul>
</div>
</div>

<div class="callout">密钥像字母转盘上反向拨动的格数。</div>

---

# 任务二：变量追踪

<div class="grid-2">
<div class="card">
<h3>解密的一步</h3>
<ul>
<li>字符 → <code>ord()</code> → 数字序号</li>
<li>减去密钥：<code>c - key</code></li>
<li>回到字母表：<code>(c - key) % 26</code></li>
<li>序号 → <code>chr()</code> → 字符</li>
</ul>
</div>
<div class="card card-highlight">
<h3>追踪时看什么</h3>
<ul>
<li>逐行高亮当前执行代码</li>
<li>观察字符、序号、密钥和结果</li>
<li>使用“上一步 / 下一步”核对变化</li>
</ul>
</div>
</div>

<div class="callout">想一想：减法得到负数时，% 26 怎样把结果绕回字母表？</div>

---

# 任务三：逻辑排雷

<div class="grid-2">
<div class="card card-warm">
<h3>发现问题</h3>
<ul>
<li>解密字符靠近A</li>
<li>减去较大的密钥</li>
<li>结果可能落到字母表范围之外</li>
</ul>
</div>
<div class="card card-highlight">
<h3>修复并验证</h3>
<ul>
<li>补上循环处理：<code>(c - key) % 26</code></li>
<li>检查括号、大小写与半角符号</li>
<li>用边界字符重新测试</li>
</ul>
</div>
</div>

<div class="callout">⭐ 挑战：如果不取模，字符序号为负时会发生什么？</div>

---

# 暴力枚举：逐个试密钥

<div class="grid-2">
<div class="card card-highlight">
<h3>实验操作</h3>
<ul>
<li>一键尝试密钥1到25</li>
<li>观察每个候选明文</li>
<li>寻找可读、符合情境的结果</li>
</ul>
</div>
<div class="card">
<h3>比较思考</h3>
<ul>
<li>密钥数量很少，尝试成本低</li>
<li>规律明显，容易被逐一破解</li>
<li>凯撒密码适合学习原理，不适合保护真实秘密</li>
</ul>
</div>
</div>

<div class="callout">尝试所有可能的密钥，也是一种“枚举”。</div>

---

# 从课堂移位到现代密码

<div class="grid-2">
<div class="card">
<h3>课堂模型</h3>
<ul>
<li>凯撒密码：规则简单，密钥空间很小</li>
<li>可用于体验加密、解密与枚举</li>
<li>不能替代真实信息保护</li>
</ul>
</div>
<div class="card card-highlight">
<h3>我国商用密码算法</h3>
<ul>
<li><code>SM2</code>：公钥密码算法</li>
<li><code>SM3</code>：密码杂凑算法</li>
<li><code>SM4</code>：分组密码算法</li>
</ul>
</div>
</div>

<div class="callout">守护真实信息，要使用合规、可靠的安全技术，不把简单移位当作保护措施。</div>
