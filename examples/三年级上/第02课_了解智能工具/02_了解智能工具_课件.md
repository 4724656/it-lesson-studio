# 任务二：机箱微型解剖台

<div class="grid-2">
  <div class="card card-highlight">
    <h3>点一点，找伙伴</h3>
    <ul>
      <li>主板：像连接各位成员的桥梁。</li>
      <li>CPU：像电脑的大脑。</li>
      <li>硬盘：像存东西的仓库。</li>
      <li>风扇：像帮助散热的小风扇。</li>
    </ul>
  </div>
  <div class="card card-warm">
    <h3>边看边想</h3>
    <ul>
      <li>要把信息存起来，谁像仓库？</li>
      <li>哪个伙伴像大脑？</li>
      <li>只观察示意图或仿真，不打开机箱。</li>
    </ul>
  </div>
</div>

# 任务二：机箱微型解剖台

<div class="grid-2">
  <div class="card">
    <h3>我来完成配对</h3>
    <ul>
      <li>主板 → 桥梁</li>
      <li>CPU → 大脑</li>
      <li>硬盘 → 仓库</li>
      <li>风扇 → 散热小助手</li>
    </ul>
  </div>
  <div class="card card-highlight">
    <h3>观察提示</h3>
    <ul>
      <li>点一个部件，看看哪里亮起来。</li>
      <li>读一读说明卡片，再说出它像什么。</li>
      <li>每次点完先观察，不要连续乱点。</li>
    </ul>
  </div>
</div>

# 任务三：键鼠练兵

<div class="grid-2">
  <div class="card card-highlight">
    <h3>鼠标单击与双击</h3>
    <ul>
      <li>单击：轻轻点一下。</li>
      <li>双击：同一位置快速轻点两下。</li>
      <li>双击像小啄木鸟轻敲两下。</li>
    </ul>
  </div>
  <div class="card card-warm">
    <h3>轮到我练习</h3>
    <ul>
      <li>按屏幕提示完成单击和双击。</li>
      <li>看清目标，再轻轻点击。</li>
      <li>没有反应：先停手，再看提示。</li>
    </ul>
  </div>
</div>

---

# 任务三：键鼠练兵
