## 一、教材分析
本课是浙教版小学信息科技六年级上册第一单元《算法的实现》第5课（课本第18~23页），承接前序算法抽象、流程图设计与代码编写，是“算法从纸面走向机器”的关键一课。教材以“鸡兔同笼”为核心情境：先在 Python IDLE 中运行程序，直观感知算法执行的高速精准；再以“调试程序”为突破口，呈现变量大小写混淆、中文全角符号、缩进缺失三大典型错误；最后针对“无解时程序无输出”的缺陷，引入状态跟踪变量 `jie` 完善算法，体会健壮性与通用性的计算思维。

## 二、学情分析
六年级学生已初步掌握 Python 基本语法与三大控制结构，并完成了鸡兔同笼初版代码。但上机时易出现“见红报错就慌、不会看行号、全角标点屡现、缩进混乱”等问题，且对算法的理解停留在“特定数字能算出即可”，缺乏健壮性考量。
本课搭建三大实战支架：
- **生活比喻**：计算机执行算法如“高铁调度员按轨道全速推进”，报错如“代码发出的求救信号”，状态变量 `jie` 如“通关信号灯”；
- **启发设问**：“人算满头大汗为何计算机只要0.01秒？”“改参数后控制台没反应是死机了吗？”
- **避坑锦囊**：调试三看——看大小写、查半角冒号、数Tab缩进。

## 三、教学目标
- **信息意识**：通过上机运行算法，直观感受计算机处理复杂问题的高效与精准，树立“用程序语言赋能问题解决”的数字化工具意识。
- **计算思维**：排查 NameError、SyntaxError 与 IndentationError 三类常见报错，掌握依报错提示定位并修复的方法；通过引入状态变量处理无解情况，体会算法必须具有明确输出的确定性与逻辑完整性。
- **数字化学习与创新**：熟练在 Python IDLE 中打开、运行、调试与修改程序，并利用单文件互动课件进行仿真验证，提升数字化探究与纠错能力。
- **信息社会责任**：理解代码规范对稳定运行的重要性，养成良好书写习惯与机房文明。

## 四、教学重点
在 Python IDLE 环境中规范打开与运行程序；理解循环结构 `while` 的执行机制与枚举思想；排查变量大小写、中英文标点、代码缩进等常见报错并掌握修复方法。

## 五、教学难点
根据 Python 错误回溯信息精确定位错误根源并独立修复；理解状态跟踪变量的“信号灯”逻辑并运用它完善算法中的无解分支，提升算法健壮性。

## 六、教学过程

| 教学环节 | 教师活动 | 学生活动 | 设计意图 |

| **一、情境激趣<br />复习导入<br />(4分钟)** | 1. 出示《孙子算经》“鸡兔同笼”（35头，94足），回顾上节课的枚举算法与 Python 代码。<br />2. 设问：“代码不通电、不执行，只是一串字符。如何让计算机真正动起来，帮我们秒出答案？人和计算机算同一道题，差在哪？”<br />3. 揭示课题《第5课 算法的执行》。 | 1. 回顾上节课的鸡兔同笼枚举代码。<br />2. 明确本课目标：上机见证算法运转。 | 从前序课时自然过渡，明确“编写”到“执行”的飞跃。 |
| **二、初试锋芒<br />运行程序初探<br />(8分钟)** | 1. 示范运行规范三步：启动 Python IDLE 编辑器 ➔【File】【Open】打开桌面的 `鸡兔同笼.py` ➔【Run】【Run Module】（或按快捷键 <kbd>F5</kbd>）。强调：规范的打开方式是后续调试的前提。<br />2. 比喻点拨：计算机执行算法就像“高铁调度员”，按既定代码轨道全速精准执行，毫秒间完成36次循环验证。<br />3. 组织学生上机运行，观察输出 `23 只鸡， 12 只兔。`，对比口算与机算的速度差异，完成导学单第一关。 | 1. 打开 IDLE 载入程序，按 <kbd>F5</kbd> 运行。<br />2. 对比口算与机算速度，体会高速准确。<br />3. 完成导学单第一关记录。 | 建立规范上机流程，体会算法落地的成就感。 |
| **三、代码排雷<br />排查三大卡点<br />(10分钟)** | 1. 下发 3 个埋雷代码，运行弹出红色报错；点拨：“报错不是失败，是计算机在发求救信号！”<br />2. 拆解三大卡点：①大小写混淆（`while Tu < 36:`）➔ `NameError`。点拨：Python 严格区分大小写，`tu` 与 `Tu` 是两个不同变量；②中文冒号（`while tu < 36：`）➔ `SyntaxError`。点拨：所有语法标点必须在英文半角状态下输入；③缩进丢失（`ji = 35 - tu` 未缩进）➔ `IndentationError`。点拨：Python 用冒号和缩进标识从属关系，缩进是代码的骨架。<br />3. 避坑锦囊：“运行前先看三处：拼写大小写、英文半角冒号、Tab缩进”。完成导学单第二关。 | 1. 运行带错程序，看控制台错误行号与类型。<br />2. 化身“代码小侦探”逐个修复 3 处 Bug。<br />3. 完成导学单第二关纠错表。 | 直击最高频痛点，变被动报错为主动调试。 |
| **四、逻辑再造<br />完善算法分支<br />(12分钟)** | 1. 挑战：“35 个头、93 只脚，答案是多少？”学生改参数运行，控制台一片空白！<br />2. 引发冲突：“算法必须有输出！空白一片让用户以为死机了，算好算法吗？”<br />3. 引出状态跟踪变量 `jie`：它就像一盏通关信号灯——初始为 0（代表还没找到解）；一旦满足条件算出答案，顺手把灯点亮为 1（`jie = 1`）；循环 36 次结束后查验：如果 `jie == 0`，就打印 `此题无解`！<br />4. 对比出示课本 P22 流程图与 P23 代码，组织学生补全无解分支，完成导学单第三关。 | 1. 改总脚数为 93 运行，体验控制台无反应的尴尬。<br />2. 理解“算法必须有明确输出”。<br />3. 学会 `jie` 的用法：循环外初始化、循环内标记、循环后判断。<br />4. 上机验证“此题无解”输出。 | 从语法正确上升到逻辑健壮性，提升算法设计全面性。 |
| **五、全课小结<br />(6分钟)** | 1. 复盘：自动化执行 ➔ 调试三大卡点 ➔ 状态变量完善逻辑。<br />2. 组织 HTML 作业答题自评，导出 `.txt` 学习凭单。<br />3. 规范整理工位、文明关机。 | 1. 复盘核心概念与调试口诀。<br />2. 完成 HTML 作业自评，下载凭单。<br />3. 整理工位，规范关机。 | 形成闭环，升华计算思维，抓实机房好习惯。 |
