### ⭐ 关卡二 · 代码侦探：排查三大常见卡点
仔细观察运行报错提示（Traceback），连线或填入对应的纠错秘籍：

| 错误求救信号 | 报错原因分析 | 侦探修复对策 |
| :--- | :--- | :--- |
| `NameError: name 'Tu' is not defined` | 变量名【______】混淆 | Python 严格区分大小写，将 `Tu` 改为 `tu` |
| `SyntaxError: invalid character` | 误用了中文全角【______】 | 切换输入法，输入英文半角冒号 `:` |
| `IndentationError: expected an indented block` | 缺失代码【______】层级 | 冒号后按 `Tab` 键或 4 个空格形成下级缩进 |
