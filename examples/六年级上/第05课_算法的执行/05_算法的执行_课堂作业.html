任务二：代码排雷

循环像绕操场跑步：每一圈都要让计数牌发生变化，否则判断条件永远成立，程序就会一直转圈。

基础通关：先点击“可疑代码”，再点击“补上修复语句”。答错可以无限重选，找到错误后才能锁定。

问题程序：为什么一直重复？

1. count = 0
2. while count < 3:
3. 　 print("第" + count + "次")
4. 　 （少了什么？）

请选择最可疑的位置。

修复工具箱

count = count + 1
count = count - 1
print("停止")

先找出循环中“不变”的变量。

调试步骤：① 找到变量没有变化的位置；② 补上让条件最终不成立的语句。

⭐ 进阶挑战星

假如把修复语句改为 count = count + 2，程序会打印几次？在脑中追踪 count：0 → 2 → 4，再说出你的判断。
