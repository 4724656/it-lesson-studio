# 算法的执行

### 让每一步都看得见，让每个结果都有来由

**算力引擎 → 代码排雷 → 逻辑再造**

---

# 一步一步，程序怎样走？

<div class="grid-2">
<div class="card card-highlight">

<h3>程序像一张菜谱</h3>
<ul>
<li>指令：按顺序完成的步骤</li>
<li>变量：随时更新的记事卡</li>
<li>判断：决定接下来走哪条路</li>
</ul>

</div>
<div class="card card-warm">

<h3>今天的追踪任务</h3>
<ul>
<li>观察指针：当前执行到哪一行？</li>
<li>观察变量：<code>x</code>、<code>y</code>、<code>count</code> 如何变化？</li>
<li>先预测，再单步执行，最后核对</li>
</ul>

</div>
</div>

<div class="callout">每次只走一步：看指令 → 更新变量 → 再看下一步</div>

# 任务一：算力引擎

<div class="grid-2">
<div class="card card-highlight">

<h3>追踪器操作</h3>
<ul>
<li>先读当前高亮的指令</li>
<li>预测会改变的变量</li>
<li>点击“单步执行”</li>
<li>对照变量表，解释变化原因</li>
</ul>

</div>
<div class="card">

<h3>我的记录</h3>
<ul>
<li>初始状态：<code>x</code>、<code>y</code>、<code>count</code></li>
<li>执行一步后：哪一项发生变化？</li>
<li>再执行一步：指针移到了哪里？</li>
</ul>

</div>
</div>

<div class="callout">CPU像照着菜谱做事的厨师；变量像每做一步就更新的记事卡。</div>

# 任务一：看见状态变化

<div class="card card-highlight">

<h3>单步执行观察表</h3>

| 执行时刻 | 当前指令 | 观察变量 |
|:--|:--|:--|
| 开始前 | 初始状态 | <code>x</code>、<code>y</code>、<code>count</code> |
| 单步一次 | 指针下移 | 变化的变量高亮 |
| 再走一步 | 执行下一行 | 记录新状态 |

</div>

<div class="callout">先预测再点击：刚执行哪一行？它会影响哪张“记事卡”？</div>

---

# 任务二：代码排雷

<div class="grid-2">
<div class="card card-warm">

<h3>循环为什么不停？</h3>
<ul>
<li>检查循环条件是否可能变成假</li>
<li>检查控制变量是否在循环内更新</li>
<li>观察程序是否重复经过同一状态</li>
</ul>

</div>
<div class="card card-highlight">

<h3>边界值也要测</h3>
<ul>
<li>测试小于阈值的输入</li>
<li>测试正好等于阈值的输入</li>
<li>测试大于阈值的输入</li>
</ul>

</div>
</div>

<div class="callout">调试不是猜答案：找到可疑语句，修改后再用数据验证。</div>

---

# 任务二：找错、修改、复测

<div class="card">

<h3>排雷记录</h3>
<ul>
<li>我发现的问题：循环条件或变量更新不合适</li>
<li>我做的修改：让控制变量按预期变化</li>
<li>我的复测：至少选两组输入检查结果</li>
</ul>

</div>

<div class="card card-warm">

<h3>避坑提示</h3>
<ul>
<li>变量没有更新，循环可能一直重复</li>
<li>只测普通值，可能漏掉临界值漏洞</li>
<li><code>&gt;</code> 与 <code>&gt;=</code> 在等于阈值时结果不同</li>
</ul>

</div>

---

# 任务三：逻辑再造

<div class="grid-2">
<div class="card card-highlight">

<h3>拼装流程图</h3>
<ul>
<li>识别判断框与处理框</li>
<li>将条件词块放进判断位置</li>
<li>把处理步骤接到对应分支</li>
</ul>

</div>
<div class="card">

<h3>检查两条路径</h3>
<ul>
<li>输入一组让条件成立的数据</li>
<li>输入一组让条件不成立的数据</li>
<li>观察“是(Y)”与“否(N)”路径</li>
</ul>

</div>
</div>

<div class="callout">流程图要能说明：条件是什么？成立时做什么？不成立时又做什么？</div>

---

# 任务三：挑战临界值

<div class="card card-warm">

<h3>⭐ 进阶挑战星</h3>
<ul>
<li>让输入正好等于阈值</li>
<li>观察执行路径是否符合任务规则</li>
<li>比较 <code>&gt;</code> 和 <code>&gt;=</code> 的不同</li>
<li>修正条件，再重新测试</li>
</ul>

</div>

<div class="callout">一句话解释你的选择：为什么这个临界值应该走“是”或“否”？</div>

---
