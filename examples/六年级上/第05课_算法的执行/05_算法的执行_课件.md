## 🔍 探秘语法：条件循环语句结构

计算机之所以能完成 36 次自动验算，核心在于 <code>while</code> 循环：

```python
tu = 0
while tu < 36:                     # 循环头部：判断条件，必须以英文冒号结束
    ji = 35 - tu                   # 循环体：严格保持 4 个空格缩进
    if ji * 2 + tu * 4 == 94:      # 分支判断：检查是否符合解题条件
        print(ji, "只鸡，", tu, "只兔。")
    tu = tu + 1                    # 计数累加：每次循环兔子数量加 1
```

<div class="grid-2" style="margin-top: 12px;">

<div class="card">
  <h3>📌 判断条件</h3>
  <p><code>tu &lt; 36</code> 决定循环是否继续。只要满足条件，就重复执行内部代码；不满足则立刻终止。</p>
</div>

<div class="card card-highlight">
  <h3>📌 冒号与缩进</h3>
  <p>循环头部末尾必须有冒号 <code>:</code>，下属所有执行代码必须整齐缩进（按一次 <kbd>Tab</kbd>）。</p>
</div>

</div>

## 🚨 任务二：代码小侦探 · 常见卡点一

在编写代码时经常会看到红色的 **Traceback 报错**。别慌！这是计算机发来的求救信！

<div class="grid-2">

<div class="card">
  <h3>❌ 故障现场（第 3 行）</h3>
  <pre><code>tu = 0
while Tu &lt; 36:
    ji = 35 - tu</code></pre>
  <div class="callout-danger">
    <strong>报错提示：</strong><br />
    <code>NameError: name 'Tu' is not defined</code>
  </div>
</div>

<div class="card card-highlight">
  <h3>🔍 侦探破案与排查</h3>
  <ul>
    <li><strong>病因诊断</strong>：变量名大小写混淆！</li>
    <li><strong>语言铁律</strong>：Python <strong>严格区分大小写</strong>，<code>tu</code> 和 <code>Tu</code> 是两个完全不同的变量名。</li>
    <li><strong>对症下药</strong>：将大写 <code>Tu</code> 修复为小写 <code>tu</code>。</li>
  </ul>
</div>

</div>

---

## 🚨 任务二：代码小侦探 · 常见卡点二

有时候仅仅是一个看似不起眼的标点，也会让程序直接罢工：

<div class="grid-2">

<div class="card">
  <h3>❌ 故障现场（第 2 行）</h3>
  <pre><code>tu = 0
while tu &lt; 36：
    ji = 35 - tu</code></pre>
  <div class="callout-danger">
    <strong>报错提示：</strong><br />
    <code>SyntaxError: invalid character '：' (U+FF1A)</code>
  </div>
</div>

<div class="card card-highlight">
  <h3>🔍 侦探破案与排查</h3>
  <ul>
    <li><strong>病因诊断</strong>：误用了中文全角冒号！</li>
    <li><strong>语言铁律</strong>：Python 的语法标记符号<strong>必须在英文半角状态</strong>下输入。</li>
    <li><strong>对症下药</strong>：按 <kbd>Shift</kbd> 切换英文输入法，重新键入标准英文冒号 <code>:</code>。</li>
  </ul>
</div>

</div>

## 🛡️ 任务三：逻辑再造 · 算法的健壮性

农夫提出了一个新问题：如果笼子里有 **35 个头、93 只脚**，结果会怎样？

<div class="grid-2">

<div class="card">
  <h3>🧪 上机实验</h3>
  <p>将代码中的 <code>94</code> 改为 <code>93</code> 运行：</p>
  <div style="background: #1e293b; color: #94a3b8; padding: 14px; border-radius: 8px; font-family: monospace;">
    ================ RESTART ================<br />
    &gt;&gt;&gt; <span style="color: #cbd5e1;">（一片寂静，毫无反应）</span><br />
    &gt;&gt;&gt;
  </div>
</div>

<div class="card card-highlight">
  <h3>⚠️ 算法特征红线</h3>
  <ul>
    <li><strong>必须有输出</strong>：算法执行完毕必须给出明确结果！</li>
    <li>没有任何输出，会让用户误以为<strong>程序死机卡死</strong>。</li>
    <li><strong>健壮的算法</strong>：有解输出解，无解明确提示“此题无解”！</li>
  </ul>
</div>

## 🚥 破局关键：引入状态标记变量 `jie`

如何让程序知道究竟是“找到了答案”还是“彻底算完了却一个都没找到”？

<div class="grid-3">

<div class="card">
  <h3>1. 初始熄灭</h3>
  <p>在循环开始前：</p>
  <p><code>jie = 0</code></p>
  <p>相当于插上一面<strong>红旗</strong>（表示当前还没有找到符合条件的解）。</p>
</div>

<div class="card card-highlight">
  <h3>2. 遇解点亮</h3>
  <p>在条件成立时：</p>
  <p><code>jie = 1</code></p>
  <p>找到答案时，顺手换成<strong>绿旗</strong>（表示成功发现了正确答案）。</p>
</div>

<div class="card">
  <h3>3. 终局裁决</h3>
  <p>在循环完全结束后：</p>
  <p><code>if jie == 0:</code></p>
  <p>如果绿旗从未被换上，果断打印 <code>此题无解</code>！</p>
</div>

</div>

## 📐 算法流程与完整代码

<div class="grid-2">

<div class="card">
  <h3>📘 完善后的算法逻辑</h3>
  <ul>
    <li>① 初始化 <code>tu = 0, jie = 0</code></li>
    <li>② 进入 36 次枚举循环</li>
    <li>③ 满足条件：<code>jie = 1</code> 并输出</li>
    <li>④ 循环全部结束：检查 <code>jie == 0</code></li>
    <li>⑤ 若无解：输出 <code>"此题无解"</code></li>
  </ul>
</div>

<div class="card card-highlight">
  <h3>💻 完善后的 Python 代码</h3>
  <pre style="margin: 0; font-size: 0.85em;"><code>jie = 0
tu = 0
while tu &lt; 36:
    ji = 35 - tu
    if ji * 2 + tu * 4 == 93:
        jie = 1
        print(ji, "只鸡，", tu, "只兔。")
    tu = tu + 1
if jie == 0:
    print("此题无解")</code></pre>
