# 任务一：指针、变量与赋值

<div class="grid-2">
<div class="card">
<h3>代码指针像书签</h3>
<ul>
<li>书签指向哪一行</li>
<li>CPU就执行哪一行</li>
<li>执行后书签继续下移</li>
</ul>
</div>

<div class="card card-warm">
<h3>赋值不是数学等号</h3>
<ul>
<li><code>x = x + y</code></li>
<li>先算右边：<code>2+3=5</code></li>
<li>再把新值写给左边：<code>x=5</code></li>
</ul>
</div>
</div>

<div class="callout">
问题：旧的<code>x</code>没有“消失”，它被新计算出的值替换了。现在请完成变量表。
</div>

# 任务二：代码排雷

<div class="grid-2">
<div class="card card-warm">
<h3>故障代码</h3>
<ul>
<li><code>count = 0</code></li>
<li><code>while count &lt;= 3:</code></li>
<li><code>&nbsp;&nbsp;输出 count</code></li>
</ul>
</div>

<div class="card card-highlight">
<h3>异常现象</h3>
<ul>
<li>屏幕不断输出0</li>
<li>循环好像停不下来</li>
<li>计数牌始终没有改变</li>
</ul>
</div>
</div>

<div class="callout">
进入探究舱“代码排雷”：先找出没有变化的变量，再补上正确语句。
</div>

---

# 任务二：用证据排除错误

<div class="grid-2">
<div class="card">
<h3>排雷步骤</h3>
<ul>
<li>① 记录循环前的<code>count</code></li>
<li>② 观察循环体有没有更新它</li>
<li>③ 判断条件会不会变成“否”</li>
</ul>
</div>

<div class="card card-highlight">
<h3>关键修补</h3>
<ul>
<li><code>count = count + 1</code></li>
<li>计数牌：0 → 1 → 2 → 3 → 4</li>
<li><code>4 &lt;= 3</code> 不成立，循环停止</li>
</ul>
</div>
</div>

<div class="callout">
不是“猜一句代码”，而是让变量变化和条件结果告诉我们：错误藏在哪里。
</div>

# 任务三：临界值是重要关口

<div class="grid-2">
<div class="card card-highlight">
<h3>两种条件，结果不同</h3>
<ul>
<li><code>体温 &gt; 37.3</code></li>
<li>37.3℃不会提示复测</li>
<li>临界值被漏掉了</li>
</ul>
</div>

<div class="card card-warm">
<h3>修正后的条件</h3>
<ul>
<li><code>体温 &gt;= 37.3</code></li>
<li>37.3℃会提示复测</li>
<li>规则与需求一致</li>
</ul>
</div>
</div>

<div class="callout">
⭐ 进阶挑战星：用36.8℃和37.3℃各测试一次，说清楚它们为什么走不同的流程线。
</div>

# 不同执行路径，步数也不同

<div class="grid-2">
<div class="card">

<ul>
<li>读取体温</li>

<div class="card card-highlight">
<h3>提示复测路径</h3>
<ul>
<li>读取体温</li>
<li>判断条件</li>
<li>显示“请复测”</li>
<li>记录或再次检测</li>

<div class="callout">
