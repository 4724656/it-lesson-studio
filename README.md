# IT Lesson Studio (中小学信息科技四位一体教学工坊)

> 专为中国中小学（小学 3~6 年级、初中 7~8 年级）信息科技/信息技术教师打造的**“四位一体”全流程备课与机房教学工作台**。  
> 课文内容一次输入，自动同源生成**规范教案 (Word)、演示课件 (Marp PPTX/PDF)、探究导学单 (Word)、机房互动作业 (HTML)**。

## 🎯 核心设计哲学

1. **同源同构，拒绝割裂**：教案的情境导入、课件的引导卡片、导学单的探究步骤与 HTML 作业的实操关卡 100% 同名同源，彻底告别“教案一套、课件一套、上机又是网上拼凑一套”。
2. **机房真离线，开箱即用 (Offline-First)**：
   - 互动作业为**纯静态单文件**，绝无外部 CDN、Google Fonts 或外链图片，双击即开，断网机房完美运行。
   - 学生完成学习后，一键 Blob 导出包含姓名、班级、成绩的 `.txt` 学习凭单，首行为结构化可 grep 标准行，极度方便教师机无服务器快速汇总收集。
3. **严格对齐学段认知与新课标**：
   - 紧扣教育部《义务教育信息科技课程标准（2022年版）》四维核心素养。
   - 完整配套浙教版 2026 新课标教材图谱（3~8 年级 240 课时），杜绝小学低段出现过于抽象的代码术语，情境贴近中小学生真实校园与生活。

## 🛠️ 环境准备与快速上手

### 1. 基础环境
- **Node.js** (>= 18)
- **Pandoc**：用于将 Markdown 编译为排版 Word 文档
  - Windows: `winget install pandoc`
  - macOS: `brew install pandoc`
- **Astral uv / Python** (>= 3.10)：用于执行自动公文排版与合规自检脚本
  - Windows: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`

### 2. 常用操作命令
```bash
# 1. 安装依赖
npm install

# 2. 🛡️ 阶段成果与学段合规全自动质检（支持直接传入课例目录，一次性全检教案、导学单、课件、作业）
npm run check:lesson examples/三年级上/第03课_了解信息处理工具/
npm run check:lesson examples/四年级上/第10课_从数据到编码/

# 3. 🚀 一键编译指定课例的所有 Word、PPTX、PDF 资产（自动触发 Python-docx 中文公文精排）
npm run export:lesson examples/三年级上/第03课_了解信息处理工具/
npm run export:lesson examples/四年级上/第10课_从数据到编码/
```

> 💡 **轻量纯净原则**：仓库仅跟踪 `.md` 与 `.html` 源码，绝无二进制膨胀。通过上述 `export:lesson` 命令，任何人均可在本地一键 100% 重建所有排版精美的 `.docx`、`.pptx` 与 `.pdf`。
