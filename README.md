# IT Lesson Studio (浙教版2026中小学信息科技备课助手)

输入课题或课文内容，一键生成配套的 4 份教学材料：  
**4页以内的教案 · 1页纸的导学单 · 大字号幻灯片 · 离线能用的随堂作业**

---

## 四样配套材料

- 📄 **备课教案 (`.docx`)**：控制在 4 页 A4 纸以内，四列表格排版，不画板书，包含通俗的生活比喻、提问话术和上机容易踩坑的提醒。
- 📋 **课堂导学单 (`.docx`)**：上机实操任务单，小学低年级严格单面 1 页，留出填空、选择与记录的空位，只用小孩子听得懂的话。
- 🖥️ **大屏课件 (`.pptx` / `.pdf`)**：Marp 16:9 幻灯片，一页讲一个任务，字大清楚，方便坐在后排的学生看清。
- 🎮 **随堂作业 (`.html`)**：单文件网页，双击用浏览器就能打开，包含小操作与选择题，导出的凭单可直接上传学习平台。

## 启动方式

### 方式 1：Docker 运行（推荐）

```bash
# 1. 拉取镜像：
docker compose pull

# 2. 启动服务：
docker compose up -d
```
打开浏览器访问：`http://localhost:3800`

> 每次代码推送到 main 分支，GitHub 都会自动打包最新镜像。

### 方式 2：本地直接运行 (Node.js >= 20)

```bash
# 安装依赖并启动
npm install
npm run web:dev
```
打开浏览器访问：`http://127.0.0.1:3800`

## 常用参数说明

默认启动就能直接用。如果需要改配置，可以在网页后台【管理员设置】里改，也可以在环境变量里写：

| 参数名 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `PORT` | `3800` | 网页访问端口 |
| `INVITE_CODE` | `ZJ2026` | 教师注册邀请码，首位注册的人自动成为管理员，免邀请码 |
| `AI_API_BASE` | `https://api.openai.com/v1` | 大模型接口地址（支持各类兼容 OpenAI 格式的接口） |
| `AI_API_KEY` | `sk-...` | 大模型 API Key（也可以登录后在网页后台直接填） |
| `AI_MODEL` | `gpt-4o-mini` | 使用的模型名字 |
| `./web/data` | *(挂载目录)* | 数据存放目录（包含账号数据库、生成的课件和压缩包） |
