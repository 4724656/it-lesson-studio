## 🌟 四大成套产物

- 📄 **备课教案 (`.docx`)**：严格 ≤4 页 A4，首行缩进两格公文精排，无板书，含生活通俗比喻、启发设问台词与实操避坑三支架。
- 📋 **探究导学单 (`.docx`)**：学生第一视角趣味任务口令，低学段严格单面 A4 封顶（杜绝跨页），含显式留白槽位与微型记录表。
- 🖥️ **大屏课件 (`.pptx` / `.pdf`)**：Marp 16:9 现代大屏卡片主题，纯净学生视角，大字号、沉浸导学。
- 🎮 **随堂作业 (`.html`)**：单文件离线断网秒开，含微型仿真器、随堂测验与通关奖状，一键极简下载凭单直传教学平台。

## 🚀 快速上手

### 方式 1：Docker 容器化启动（推荐）

```bash
# 启动服务
docker compose up -d
```
打开浏览器访问：`http://localhost:3800`

### 方式 2：本地直接运行 (Node.js >= 20)

```bash
# 安装依赖并以热重载模式启动
npm install
npm run web:dev
```
打开浏览器访问：`http://127.0.0.1:3800`

## ⚙️ 核心参数与配置说明

系统采用**开箱即用**设计，默认启动即可自动运行。若需自定义，可在 `docker-compose.yml` 的 `environment` 中声明，或**直接在网页端【管理员控制台】动态设置**：

| 参数名 | 默认值 | 作用说明 | 配置建议 |
| :--- | :--- | :--- | :--- |
| `PORT` | `3800` | Web 界面与 API 监听端口 | 宿主机按需映射即可 |
| `INVITE_CODE` | `ZJ2026` | 教师注册专属邀请码 | 防外人滥用；**首位注册用户自动成为超管免邀请码**；管理员可在网页随时修改 |
| `JWT_SECRET` | 内置长密钥 | 登录 Token 鉴权签名密钥 | 开箱自带安全兜底；公网部署推荐配置任意随机字符串 |
| `AI_API_BASE` | `https://api.openai.com/v1` | 大模型 API 端点 (OpenAI 兼容) | 可在网页后台随时修改，优先级高于环境变量 |
| `AI_API_KEY` | `sk-...` | 大模型 API 密钥 | 可在网页后台输入，持久化保存在本地 SQLite |
| `AI_MODEL` | `gpt-4o-mini` | 生成四件套使用的大模型名称 | 支持任意 OpenAI 兼容模型（如 `gpt-4o-mini`、`deepseek-chat`、`gemini-2.5-flash` 等） |
| `./web/data` | *(挂载目录)* | 数据持久化存储目录 | 存放用户账号、SQLite 数据库 (`app.db`) 以及生成的全套课件与打包文件 |
