# 模块四：随堂互动作业｜离线数字化探究舱

本文件仅是主 SKILL.md 的模块四，继承全局教材依据、教师输入与四件套任务同源规则。模块内 P0/P1/P2 表示验收严重性，不是工程开发阶段。

目录：目标与优先级；交付契约；教学闭环；学生状态；仿真真实性；范式选择；评价闭环；可靠性；分层验收。

> **HTML V2 · 模块修订稿**｜适用：3—8 年级信息科技与人工智能课程。用于指导生成**可在机房直接打开的单文件 HTML 互动课堂**。本模块是设计与验收规范，不是固定的关卡模板。
>
> **保留的核心**：教师设想优先、35—40 分钟探究主线、分层通关、先选后判、12 册范式参考、五件套学习闭环、离线运行与心理安全。
>
> **本版调整**：删除重复技术禁令与冗长示例代码；修复“不可卡死”与“未通关不能前进”的冲突；区分必须遵守与可以灵活设计的要求；新增**真实探究判据、状态模型、无障碍替代操作、仿真真实性、验收场景**。

## 0. 目标与交付物

生成的互动页面应让学生在教师巡视辅导下完成一个相对完整的学习过程：**发现问题 → 操作试验 → 观察反馈 → 解释原因 → 迁移应用 → 自我评价**。

它不是将教材做成翻页课件，也不是让学生连续刷选择题。**主要时间必须花在有认知价值的操作、比较、试错和解释上**；不靠等待动画、重复点击或强迫做题凑足课时。

**交付物**：

1. 一个可离线运行、无需安装的 `.html` 文件（HTML/CSS/JS 全部内联）。
2. 回复教师的 **3—5 行使用说明**：适用册次、主任务和基础判据、进阶挑战、预计时长、必要的设计取舍。说明**不写进学生页面**。

**三个不可牺牲的体验目标**：

- **人人能参与**：基础任务可达成，进阶任务有深度；不会因卡在某一步被困住。
- **断网也可靠**：双击打开即可使用，功能不依赖服务器、账号或第三方资源。
- **反馈有尊严**：错误得到解释；求助、跳过或表示“还没懂”不受羞辱或惩罚。

## 1. 规则优先级与输入处理

| 层级 | 约束 | 执行方式 |
|---|---|---|
| **P0 · 必须** | `references/output-spec.md` 中 `spec-yaml` 的机器门禁、页面离线可运行、凭单数据格式与本模块明确规定的不可破坏契约 | 必须通过，不能用美观或教学设想替代 |
| **P1 · 教学优先** | 教师的“教学设想与特别说明”；具体课题的学习目标、典型误区和学情 | 在 P0 范围内优先保留教师的任务情境和关键操作 |
| **P2 · 参考建议** | 本模块推荐的屏幕编排、时间分配、范式矩阵、动效和装饰 | 可按课题调整，不得为了凑数量机械照搬 |

**冲突处理**：优先保留教师设想中的**核心学习行为**，再合并场景或简化外观；绝不能通过增加无效点击或虚假仿真来满足形式。若取舍影响教师原意，须在交付说明中点明。

**识别课程信息**：优先使用明确给出的年级、上下册、课题和教师设想；只有证据充分时才推断册次，并标注“推断”。缺乏关键信息时先确认；若被要求直接生成，应清楚写明工作假设，不将猜测宣称为教材事实。12 册矩阵只是**设计参考**，不是对实际教材每课内容的权威映射。

> 数值只读取仓库 `references/output-spec.md` 的 `spec-yaml`；不维护缺省数值副本。

## 2. P0 交付契约（硬性验收）

### 2.1 文件、元数据与兼容性

- [ ] **单文件 HTML**，无需网络、安装、构建工具或第三方依赖；CSS、JS、SVG、图片资源均内联；不得调用外部脚本、样式、字体、图片、API 或跨域请求。
- [ ] 学生页面不使用 `alert()`、`confirm()`、`prompt()` 阻断式弹窗；统一使用**页内反馈**或可访问的自定义对话框。
- [ ] 有 `lang="zh-CN"`、`charset="UTF-8"`、移动端 viewport、与课题一致的 `<title>`、`<meta name="lesson-grade" content="N">`，其中 `N` 为 `3`—`8` 的单个数字。
- [ ] 屏数、动手实操屏数、导语字数、测验题量和题干字数**逐项符合实际 `spec-yaml`**。最后一屏的终极关卡计入总屏数。
- [ ] 真正的动手屏标记 `data-panel-type="hands-on"`；每屏导语容器使用 `data-prose`；测验题目以 `const quiz = [...];` 声明，**保留结尾分号**。
- [ ] 不强制填写班级、姓名，不要求登录；离线、禁用存储和下载失败时均不得造成页面整体不可用。

**离线扫描**：禁止外部资源加载与网络访问；教材网址文本和标准 SVG 命名空间字符串不视为联网。禁止项针对**生成的 HTML**，不要求以删掉教材或教师资料的自然语言来冒充安全性。

### 2.2 终极关卡五件套（缺一不可）

**① 随堂测验** `const quiz = [...];` → **② 四枚动态徽章** `medalDefs` / `.medal` → **③ 自我评价** → **④ TXT 学习凭单** → **⑤ 电子通关奖状** `#certModal`。

这五件套必须真正可操作、可验证，不能只有静态摆设。详细交互与数据约定见第 7 节。

## 3. 教学主线与时长：让互动服务理解

### 3.1 推荐的课堂节奏

**痛点体验 → 原理建模 → 主沙箱探究（基础 + ⭐）→ 调试或迁移 → 终极关卡与反思。**

不同课题可以合并环节。**至少一项任务需要学生通过多次操作产生可比较的结果，并据此作出判断**；不能全是阅读、单击揭示或换皮选择题。

按真实年级门禁合并环节；时间为教学估算，不是等待计时器。低段围绕一个主探究小步推进；中高段通过建模、调试与迁移增加思维深度。整节课覆盖预测、典型误区和迁移，不要求每个小关卡都重复五项内容。

### 3.2 什么才算动手实操屏

只有**同时符合**以下条件才能标记 `hands-on`：

1. **真实任务**：学生要调参、连线、构建、排序、运行、比较或调试，至少经历**两步有意义的操作**。
2. **可观察反馈**：改变输入后，模型状态、数据、动画、测试结果等有即时、可解释的变化。
3. **明确判据**：基础通关条件能由程序判定，并有可选的 ⭐ 深度挑战。
4. **概念关联**：操作结果能让学生理解本课某个原理，而不只是为了“把按钮点完”。

**禁止**把阅读页、点开提示、单击翻卡或“下一步”包装成动手屏。

### 3.3 每个主关卡的最小教学闭环

以一张任务卡呈现五项内容，尽量**少字、可操作**：

- **身份与目标**：用一句话说明“要解决什么问题”。
- **预测**：先让学生选一个猜想、参数或方案；不是每课都必须设独立预测页。
- **试验与证据**：调整至少一个关键变量，比较结果；若随机因素存在，应可复现实验条件。
- **错误与解释**：设置**一个符合本课的典型误区**，让学生看到为什么错，并知道如何改。
- **通关与迁移**：基础判据紧扣目标；⭐ 挑战改变边界条件、加入故障、要求迁移或优化，而非把同题机械重复十次。

如果某项不适合课题，允许等价替代，但不能缺失“**操作—反馈—理解**”的核心链条。

## 4. 分层通关与学生状态：不困住、不虚奖

### 4.1 任务状态（统一约定）

建议将每项任务区分为：`未开始` → `探索中` → `独立通关 / 带提示通关 / 暂时跳过`；⭐ 挑战另记是否达成。

- **基础通关**：每关写清**可由程序验证**的达标条件；不靠“学生点击我完成了”代替实际行为。
- **渐进提示**：第一次错误提示**观察方向**；再次错误提示**关键变量**；需要时提供**可解释的示范**。示范后允许标记为“带提示通关”，不能冒充“独立完成”。
- **允许暂跳过**：**上一屏、下一屏始终可导航**；未完成任务时，显示“基础任务尚未完成，你可以继续试试或稍后回来”，并提供帮助。跳过不授予通关徽章，但**不阻止进入终极关卡**。
- **⭐ 进阶**：完成基础后解锁 1—2 个有意义的挑战（不要求所有人都做）；达成后记录成就。进阶不应反过来影响基础通过状态。
- **重置不抹成长**：重置只恢复当前实验场景；已取得的 `xxxEver` 成就只增不减。若需开始**全新的一轮课堂**，必须有清楚区分的“重新开始整节课”操作及非阻断式二次确认。
- **回看不丢进度**：切屏返回时保留合理的实验状态；页面刷新后可尝试恢复，但存储不可用时应正常运行。

> **关键区分**：学习支持不能被误写为作弊；但“看示范后完成”和“独立完成”在徽章与教师反馈上要诚实地区分。**鼓励所有学生，不伪造达标结果。**

### 4.2 教师巡视（轻量、非监控）

页面顶部可常驻：

- **🚩 一键求助旗**：点击显示醒目的“我需要帮助”横幅，再点取消。它是学生主动表达需要，不自动上传身份或行为记录。
- **📍 进度胶囊**：显示当前屏、基础任务状态及 ⭐ 进度；屏幕距离较远时也要能辨认。

保持紧凑，不遮住主要操作区；不增加教师端后台、不收集逐项行为轨迹。

## 5. 输入、反馈与仿真真实性

### 5.1 低负担输入

| 学段 | 优先交互 | 避免的问题 |
|---|---|---|
| 3—4 年级 | 点选、分类、拖放/点放、开关、少量词语 | 长篇输入、小字按钮、只支持精细拖拽 |
| 5—6 年级 | 流程块、二进制开关、阈值与条件控制 | 只有读题答题，没有过程反馈 |
| 7—8 年级 | 变量追踪、网络配置模拟、代码单步、参数实验 | 伪代码不可运行、结果与模型不一致 |

**输入容错**：文本判定按具体目标选择 `trim()`、中英标点/空格规范化、全半角转换与大小写容错；**不能把有意义的空格、大小写或格式差异无条件抹掉**（例如代码、密码与精确格式任务）。中文输入法组合输入过程中不抢判、不卡焦点。数字输入按目标约束范围并给出可理解的报错。尽可能从**同一模型/函数**计算正确答案与动态结果，不同时维护两套容易冲突的硬编码结果。

### 5.2 可信模拟边界

- 网络、路由、AI 分类、物联网等可离线模拟，但要标清**“模拟演示”**，不要暗示已调用真实网络或大模型。
- 教学简化模型必须明确**它能展示什么、不能代表什么**。例如简化散列只能说明输入变化与摘要变化，不宣称具备密码学安全强度。
- 关键算法要逻辑自洽：相同输入和条件给出一致结果；算法边界值、状态转换、错误处理能解释；如引入随机性，应提供重试或固定种子的可复现方式。
- 涉及 HTML 预览时，优先使用**固定标签白名单的安全渲染**；如用 `<iframe sandbox srcdoc="…">`，不得授予不必要的脚本和同源权限，不执行学生提供的脚本。

## 6. 12 册能力进阶与仿真范式参考

> **仅作生成设计的灵感库**，不替代当前教材目录和教师指定教学目标。**先看课题，再选范式**；同一册次不等于所有课都用同一种交互。每课通常挑一个主模型，必要时加一个迁移模型即可。

只按已确认册次读取 `references/classwork-v2-patterns.md` 中对应的一行；教师设想可以替换默认范式。

**选型检查**：仿真与本课核心概念是否一一对应？错误现象是否真实可观察？通关判据能否检测学生完成了目标任务？如任一答案是否，应换范式而不是只换皮肤。

## 7. 终极关卡：评价闭环五件套

### 7.1 先选后判的随堂测验

- 使用 `const quiz = [...];`，对象统一使用 `q`（题干）、`options`（选项）、`correct`（从零开始的正确索引）、`why`（解释）。题量和题干长度以 `spec-yaml` 为上限，不机械凑满。
- 以**迁移理解、常见误区辨析**为主，避免只考页面上刚出现的字面定义；题目答案与仿真模型一致。
- **点击选项只记录 `.picked`**，可改选，不能提前变红绿或透露对错；点击统一的“提交并判分”后才标记 `.correct` / `.wrong`、显示 `✔/✘`、总分与逐题解析，并锁定本轮正式提交。
- 未完成选择时提示还差几题；可提供明确的“我暂时不会”路径，记为未答或不得分，**绝不以答不出来为由阻断学习闭环**。正式成绩只在统一提交时计算；提交后可回看与练习，但不覆盖首次正式得分。
- 得分由 `正确题数 ÷ 总题数 × 100` 得到整数百分制（除非输出规范另有计算规则）。**一次提交是课堂凭单约定，不是防作弊机制**；不能宣称本地 HTML 能防篡改。

### 7.2 四枚动态通关徽章

- 用 `medalDefs` 描述**本课专属的 4 枚徽章**，在 `.medal` 容器动态点亮；不能只是永远亮着的装饰。
- 主动求助或自评只能点亮学习品质徽章，不能替代知识达标或独立完成。推荐 3 枚学习成就（基础探索、⭐挑战、调试/迁移）+ 1 枚学习品质（如复盘或主动求助）；成就由实际可验证的事件驱动。
- 用 `basicEver`、`starEver`、`fixEver`、`selfEver` 等“曾达成”状态记录，重置实验场景不清除；**标称“独立完成”的徽章不能由查看完整示范直接触发**。

### 7.3 自我评价（不制造压力）

提供 3—4 项直白选项，至少包括：

- 我能解释今天一个关键现象；
- 我尝试过调整方案或修复问题；
- 我完成了 ⭐ 挑战或愿意继续试试；
- **我还没完全懂，需要老师或同伴帮助。**

允许多选，包括看似相反的成长体验。选择“还没懂”后给予尊重性的页内回应与可选的【🚩 求助】入口；**不扣分、不影响奖状称号、不把该项写入凭单**。自评完成可以点亮相应品质徽章，不要求强制勾选某一“正确态度”。

### 7.4 极简 TXT 学习凭单（平台格式契约）

- 姓名、班级**始终选填**；未填时按原约定使用 `小极客` / `本班`。提交测验后即可一键导出，**不以基础关卡或徽章全满作为条件**。
- **第一行必须精确为** `# 班级|姓名|课题|得分|时间`；第二行为对应五个值，按此顺序使用 `|` 分隔，末尾换行。例如：

```text
# 班级|姓名|课题|得分|时间
三年级2班|小明|二进制灯泡|100|2026-10-21 10:30
```

- 文件名：`班级_姓名_课题_得分.txt`。班级、姓名、课题应统一清理文件名非法字符、换行、制表符和竖线，并合理限制长度，防止破坏分隔字段。
- 用 `Blob` + `download` 生成 `text/plain;charset=utf-8` 的 UTF-8 文本，**不加 BOM**（如外部 `output-spec` 另有要求则优先遵守）；下载后释放 `ObjectURL`。
- 禁止任何姓名校验弹窗；始终提供【查看／复制凭单】入口，使用与下载完全相同的文本；不要依赖浏览器准确识别下载失败。页面不得声称已自动上传平台：**离线页面只负责生成凭单，不负责提交**。
- **不得误导**：本地生成的文本无法保证不可伪造；如平台需身份认证、签名或成绩防篡改，那是上游平台能力，不属于此单文件作业可承诺的范围。

### 7.5 现场电子通关奖状

- 使用 `#certModal` 展示**纯 CSS 的精美奖状卡**，包含班级/姓名兜底、课题、正向称号、日期、已获徽章。
- **任何学生均可打开奖状**；即使跳过任务或未满分，称号也采用真实且正向的措辞（如“勇敢探索者”），不虚称完成了尚未完成的关卡。
- 自定义对话框支持 `role="dialog"`、`aria-modal="true"`、可识别标题、Esc 关闭、关闭按钮、焦点进入与返回；点击遮罩关闭可选，但不得作为唯一退出方式。

## 8. 页面体验与系统可靠性

**视觉与操作**

- 采用统一的任务导航和视觉层次：课题/当前任务 → 可操作模型 → 观察区/反馈 → 帮助与导航；不要把一屏做成十几个花哨卡片。
- 低段主操作目标建议 ≥48px、字号 ≥18px；中高段操作目标建议 ≥40px、字号 ≥16px。检验 1366×768 与 1024×768，核心按钮、反馈、下一步无需浏览器缩放即可用。
- 所有拖拽交互提供**点选—点放**或按钮替代；核心操作支持键盘，具有清晰焦点样式；颜色不得是唯一判据，成功/失败伴随文本与符号。
- 状态反馈要说**“变化了什么、为什么”**。非必要动画从简，遵循 `prefers-reduced-motion`；音频默认关闭，允许静音操作。

**稳定与隐私**

- 离开页面屏幕时暂停不必要的动画或循环；重复点击、快速切屏、误操作和重置均不应造成状态错乱。
- 如用 `sessionStorage` 暂存进度，所有访问均需 `try/catch`，失败就使用内存状态；**不能承诺无痕/隐私模式及所有 `file://` 环境都能恢复刷新前的记录**。
- 页面无外部埋点、不联网，不采集额外个人信息；仅在需要导出时读取选填姓名/班级。提示学生：**凭单下载在本机，是否交给老师由课堂安排决定**。
- 可选的教师提示、求助旗、进度胶囊不应覆盖模型；不制造排行榜、速度排名或同伴比较压力。

## 9. 生成后验收清单（按失败严重性排序）

机器检查负责结构与格式，浏览器验证真实行为，教师审查概念与探究价值；分别报告证据，不能相互替代。

### P0：不过关就必须修复

- [ ] **门禁**：实际 `spec-yaml` 的屏数、`hands-on` 数、导语字数、测验题量/题干长度与标记均通过；没有只凭目测的“合规”。
- [ ] **离线**：断网后双击 HTML 所有关键任务都能工作，无外部资源加载；浏览器无阻断性 JS 错误。
- [ ] **过程**：至少一个真实多步探究环节；输入、反馈、基础判据来自同一套逻辑，错误和边界值可解释。
- [ ] **导航**：可返回、可求助、可跳过、可到终极关卡；“未通关不让前进”不能出现；重置不会抹掉既得成就。
- [ ] **测验**：选中时不泄露对错；提交后统一评分与解析；不能借“暂时不会”路径暗改正确率。
- [ ] **五件套**：四枚徽章真正动态变化；自评含“还没懂”；凭单前两行严格匹配平台约定；奖状可打开可关闭；姓名班级选填。
- [ ] **兜底**：存储禁用、下载失败、名字含特殊字符时仍有可用路径，页面不白屏。

### P1：直接影响课堂体验，应完成

- [ ] **三类学生试走**：快速学生有 ⭐ 深探究；一般学生能独立完成基础任务；暂时不会的学生能看提示、跳过、求助且不被羞辱。
- [ ] **误区有价值**：至少一个真实误概念能在模型中被验证和纠正，而不是弹一句“答错了”。
- [ ] **设备操作**：分别检验鼠标、键盘、触控替代操作和中文输入法；低分辨率下无主要元素被裁剪。
- [ ] **教学解释**：学生看完反馈能回答“改变哪个变量导致什么结果”，而非只知道几颗星。
- [ ] **仿真标识**：涉及 AI、网络、密码学教学简化时，能力边界表述准确，不声称虚假的联网、强加密或实际智能。

### P2：锦上添花，可按时间选择

精细动效、音效、更多皮肤、额外彩蛋和附加挑战；只在**不增加操作噪声、不损害性能、不挤占核心探究时间**时添加。

## 10. 生成器的最终执行指令

**先解析教师课题与设想 → 确定学生应理解的一个核心概念及典型误区 → 选择最能呈现该概念的主仿真 → 写出基础与 ⭐ 的程序化判据 → 按实际 `spec-yaml` 组屏 → 接入五件套 → 逐项自测 → 交付 HTML 与教师小贴士。**

严禁以“漂亮但不可操作的课件”“全套按钮拼贴”“只会判对错的选择题”“表面多屏、实际重复”“伪造真实 AI 或网络结果”代替课堂探究。

**最终判断标准不是页面有多少功能，而是学生能否亲手操作、看到因果、解释变化、修正误区，并带着尊严完成课堂。**

若任务缺少可验证的学习判据，先调整任务设计；不得用补标记、删功能、自动授奖或固定成功结果代替修复。代码字段、生命周期和事件接口统一见 `references/classwork-v2-contract.md`，不在教学模块中重复维护。
