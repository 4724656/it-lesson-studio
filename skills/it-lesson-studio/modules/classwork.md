# 模块四：🌐 随堂互动作业（3~8年级单文件离线探究页）

> 本文件与 `skills/4-classwork/SKILL.md` 保持一致。数值门禁唯一口径见 `references/output-spec.md`。

## 🎯 角色定位
你负责编写中小学信息科技机房随堂互动作业。随堂互动作业是**学生进机房打开浏览器直接操作的单文件 HTML 页面**，支撑课堂 35~40 分钟的自主上机探究、动手实验与当堂评价。

设计准则：**界面直观好操作、机房点击防手滑、声光集星有反馈；认知难度严格匹配学段，全篇说学生听得懂的大白话，不超纲拔高。**

---

## 一、 3~8 年级学段认知阶梯与交互要求

- **小学低段 (3~4年级)**：具象思维为主，打字较慢。采用 SVG 生活场景插画、脉冲热点、两步点击配对/归类、词块选填表；题干 ≤ 30~34 字，口语大白话，不出现代码与底层概念。
- **小学高段 (5~6年级)**：具备初步因果推断与逻辑思维。采用仪表盘控制台、流程图词块插槽、单步代码追踪、Bug 排雷修复、阈值滑块测试；题干 ≤ 40~44 字，聚焦生活规则与分支判断，不考死记语法。
- **初中阶段 (7~8年级)**：具备符号化抽象建模能力。采用动态编码转盘、网络拓扑连线、传感器折线图、单步/连播追踪、边界样例测试与批量枚举实验；题干 ≤ 50~54 字，聚焦因果机理与系统规律，不搞大学推导。

---

## 二、 常用交互组件与基础底座

1. **原生 SVG 场景插画与脉冲热点**：使用内联 `<svg viewBox="0 0 640 360">` 绘制场景，叠加脉冲热点按钮（`.hs`），点击变绿打勾（`.found`）并解锁详情卡，配备“💡 给我一点提示”抖动提示。
2. **两步点击法配对与分类（防鼠标拖拽手滑）**：左右配对（先点左 `.sel`，再点右配对）与收纳盒归类（先点卡片 `.chip.sel`，再点分类盒 `.box`），配完点击检查，支持重置。
3. **零依赖 Web Audio 合成音效与静音开关**：用 `AudioContext` 编写 `beep()`、`good()`、`bad()`，顶栏配备 `🔊 / 🔇` 静音开关。
4. **顶栏集星器（⭐）+ 顶部 Toast + 右下角小助手（🤖）**：顶栏常驻 `<span class="h-star">⭐ 0</span>`；顶部 `.toast` 非阻断提示（严禁 `alert/confirm/prompt`）；右下角 `.mascot` 点击弹出操作锦囊。
5. **核心动手仿真实验台**：每课 1~3 个动手屏（标记 `data-panel-type="hands-on"`），内设“基础通关任务”与 `⭐ 进阶挑战星`。
6. **`localStorage` 自动存盘**：用 `try/catch` 包装 `localStorage`，自动保存班级、姓名、各关进度与测验得分，防止机房误刷新丢失进度（在禁用存储的沙箱环境中自动退化为内存状态，不报错）。

---

## 三、 终极关卡：达标测验 + 自我评价 + 学习凭单导出

末尾屏包含以下三部分（不设虚拟徽章墙和弹窗奖状）：
1. **随堂测验 (`const quiz = [...];`)**：严格**先选后判**，点击选项只加 `.picked`，点击提交按钮后统一判分、标红绿并显示解析。
2. **自我评价打卡**：3~4 项复选框，最后一项必须包含 `我还没完全懂，需要老师或同伴帮助`。
3. **学习凭单导出 (`.txt`)**：姓名与班级选填（未填默认 `小极客` / `本班`），点击一键下载或复制凭单，首行固定为 `# 班级|姓名|课题|得分|时间`，次行为对应五个字段值。
