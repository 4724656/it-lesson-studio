# 教学技能说明 (Skills)

这里放的是生成四个教学材料的提示词规则。

之前把教案、导学单、课件、随堂作业全挤在一个文件里，AI 很容易“串味”——把写给老师看的教育学大词抄到小学生的作业里，导致题目出得太深、太难，小孩子根本读不懂。

现在拆成 4 个独立目录，各管各的：

```text
skills/
├── 1-lesson-plan/      # 📝 备课教案：给老师备课和教研检查用，控制在 4 页 Word 内，四列表格排版
├── 2-worksheet/        # 📄 课堂导学单：发给学生上机看的纸质单，优先单面 1 页，留作答空位，只用大白话
├── 3-slides/           # 🖥️ 演示课件：机房大屏投影用，Marp 16:9，一页一个任务，字大清楚
└── 4-classwork/        # 🌐 随堂作业：单文件 HTML，双击在浏览器直接打开，做完导出凭单上传学习平台
```

## 核心规矩

1. **同一个课题，任务名称要对得上**：教案里的环节、课件的页面、导学单和小作业里的任务名字必须一致，别让学生搞混。
2. **跟小孩子说话要用小孩子的话**：导学单和随堂作业是给学生看的，严禁塞进成人学术词汇。三年级、四年级以直观动手和生活常识为主，坚决不超纲，严禁考没学过的深奥概念。
3. **互不干扰，方便单项修改**：改作业的交互不会影响教案的排版，改课件样式也不会影响作业代码。
