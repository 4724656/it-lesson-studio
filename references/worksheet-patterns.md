# 课堂导学单 (Worksheet) 规范与题型模式库

> 本文档为中小学信息科技“四位一体”教学工坊的**课堂上机导学单**专属规范文档。所有导学单的设计与生成必须严格遵守本文档中定义的物理篇幅硬约束与结构模式。

---

## 一、机房实战背景与篇幅铁律

在真实的中小学信息科技机房环境中，一堂课通常为 **40~45 分钟**。
- **低年级学生（3~4 年级，8~9 岁）**刚接触计算机，手眼协调和打字速度较慢，若导学单篇幅过长、文字过密，学生不仅看不完，更无法在上机实操中同步记录。
- **教学成本与低碳环保**：学校机房打印成本严格受控。因此，导学单必须严格遵从物理纸张限制。

| 学段划分 | 物理纸张原则 | 篇幅上限 | 任务容量 | 典型交互题型 |
|:---|:---|:---:|:---:|:---|
| **小学低年级 (3~4年级)** | **单面 A4 封顶（严格 1 页，绝不翻页）** | 250~450 字 | 2~3 个微任务 + 1 个打卡 | 图文连线、选填序号、打勾 `[ ]`、拼音/数字极简输入 |
| **小学中高段 (5~6年级)** | **单面 A4 优先（复杂项目大课上限双面）** | 350~600 字（双面封顶 1000 字） | 核心探究 + 仿真演练 + 自评 | 流程图填空、参数记录表、代码积木速配、故障排查 |
| **初中阶段 (7~8年级)** | **单面 A4 优先（复杂项目大课上限双面）** | 400~650 字（双面封顶 1100 字） | 算法预演 + 代码分析 + 总结 | 算法推导、数据结构表、Python关键语句填空、综合反思 |

## 二、小学低年级（3~4 年级）单面 A4 标杆骨架

### 1. 结构要素（自上而下，严格一页收口）
1. **标题与抬头（1 行）**：课题名称 + `班级：____ 姓名：____ 评价：⭐⭐⭐`（去除冗余座号，杜绝折行）
2. **通关目标（1 句）**：使用儿童化、趣味化的通关口令，杜绝教案中复杂的学术四维素养描述。
3. **⭐ 第一关：基础认知 / 趣味匹配**：采用紧凑表格连线，或选择序号填空。
4. **⭐⭐ 第二关：核心解密 / 知识选填**：给出清晰备选词库，填入序号，降低识字书写负担。
5. **⭐⭐⭐ 第三关：上机实操 / 动手打卡**：规范坐姿与操作步骤，完成一项勾选一项 `[ ]`。
6. **🏆 习惯养成与星级自评（1~2 行）**：下课文明关机、工位整理，自评星级。

### 2. 标准 Markdown 模板示例（通用结构骨架）

```markdown
# 第X课 [课题名称] · 课堂导学单

**班级**：__________ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; **姓名**：__________ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; **评价**：⭐⭐⭐

> 🎯 **通关目标**：[根据具体课文提取 1 句话儿童化趣味口令]

### ⭐ 第一关：火眼金睛 · [任务副标题]
[极简题干说明，不超过20字]：

| 工具/概念 | 核心功能与特征 | 连线/匹配 |
|:---|:---|:---:|
| **A. 项目一** | ① 描述一 | A ➔ （ &nbsp; ） |
| **B. 项目二** | ② 描述二 | B ➔ （ &nbsp; ） |
| **C. 项目三** | ③ 描述三 | C ➔ （ &nbsp; ） |

*💡 拓展小贴士：[1行微型信创或安全提示]*

### ⭐⭐ 第二关：透视探秘 · [任务副标题]
[引导语]：  
**备选库**：① 选项A &nbsp;&nbsp; ② 选项B &nbsp;&nbsp; ③ 选项C &nbsp;&nbsp; ④ 选项D

1. 描述一（&nbsp;&nbsp;&nbsp;&nbsp;）。
2. 描述二（&nbsp;&nbsp;&nbsp;&nbsp;）。
3. 描述三（&nbsp;&nbsp;&nbsp;&nbsp;）。

### ⭐⭐⭐ 第三关：上机实操 · [任务副标题]
端正坐姿，规范操作电脑，完成一项在方框里打“√”：

- [ ] **动作一**：规范握持/快捷操作说明。
- [ ] **动作二**：双击启动软件或完成探究实验。
- [ ] **键盘/输入体验**：在编辑区输入姓名拼音：`__________________`

### 🏆 机房好习惯与自评打卡
- [ ] **文明上机**：下课主动点击【开始】➔【关机】，不直接拔电源。
- [ ] **工位整洁**：键盘推入键盘槽，鼠标摆正，椅子轻推入课桌下。
- **今日我的自评**：[ ] ⭐ 基础通关 &nbsp;&nbsp;&nbsp;&nbsp; [ ] ⭐⭐ 熟练标兵 &nbsp;&nbsp;&nbsp;&nbsp; [ ] ⭐⭐⭐ 探索小达人
```

## 三、中高年级与初中（5~8 年级）长情境/项目式大课拓展骨架（上限双面）

> 提示：中高年级常规课**优先采用单面 A4（1页）**。仅在包含多步骤实验或复杂算法项目的长课时，才采用以下双面骨架，**上限封顶 2 页，严禁注水凑篇幅**。

### 1. 正面（第 1 页）：【导学准备 + 核心探究】
- **标题抬头**：课题 + `班级：____ 姓名：____ 评价：⭐⭐⭐`（去除座号）
- **探究情境与驱动问题**：生活化真实情境引入（如“智慧农场大棚温湿度自动控制”）。
- **知识热身 / 概念辨析**：2~3 题客观辨析，激活前置知识。
- **核心实验 / 上机探究记录表**：
  - 探究步骤清晰；
  - 数据记录表（输入数据 ➔ 处理过程 ➔ 输出结果）。

### 2. 反面（第 2 页）：【分层进阶 + 成果评价】
- **三星进阶闯关**：
  - ⭐ **基础星（全员必做）**：核心功能实现或代码积木搭建。
  - ⭐⭐ **进阶星（小组协作）**：参数调优、分支逻辑补充或异常处理。
  - ⭐⭐⭐ **挑战星（拓展拔高）**：算法优化、创新设计或现实问题迁移。
- **探究反思记事簿**：
  - “我在实操中遇到的 Bug”与“我是怎么解决的”。
  - 极简自评打卡（3~4项清单）。

## 四、导学单排版避坑指南（Word / Pandoc 优化）

1. **避免多重分割线 `---`**：
   - Pandoc 对每一个 Markdown 分割线都会渲染为一个独立的带间距段落，会无形中占据 1~2 行垂直高度，极易导致溢出到第 2 页。不同关卡直接用 `###` 小标题分隔即可。
2. **严禁出现大段空白横线**：
   - 避免写 `我的体会：________________________________________________________` 连排四五行。
   - 三年级小学生手写速度慢，导学单上的文字输入留白应限制在 15~20 个字符以内。
3. **表格紧凑化**：
   - 表格行数控制在 4~5 行以内；
   - 列宽比例适中，连线匹配列保持居中；
   - 避免在表格单元格内换多个段落。
4. **符号标准化**：
   - 勾选方框统一采用 `[ ]`；
   - 填空括号统一采用全角加空格 `（ &nbsp; ）`；
   - 星级统一采用 `⭐`、`⭐⭐`、`⭐⭐⭐`。
