# 模块四仿真范式参考（按册次加载）

不是教材事实来源；教师设想在硬性契约内优先，册次不明确时不强推范式。

| 册次 | 可选主仿真范式 | 基础任务 → ⭐ 深度挑战（示例） |
|---|---|---|
| **三上** | 数字设备作用体验；虚拟浏览器下载辨识；文件类型分类箱 | 按用途选设备/识别安全下载提示/按类型分类 → 处理易混文件名与“改后缀≠改格式” |
| **三下** | 图片裁剪滤镜台；音频波形台；AI 提示词拼搭 | 调整到目标效果/组装清晰指令 → 在大小限制或模拟反馈下优化方案 |
| **四上** | 二进制灯泡阵列；生活编码器；动态图表 | 点亮指定数值/按规则生成编码 → 反读编码、判断误导性图表 |
| **四下** | 像素点阵；字符编码查看器；奇偶校验矩阵 | 根据编码还原图案/补校验位 → 定位单比特翻转；区分校验与纠错条件 |
| **五上** | 流程图拼装；红绿灯条件沙箱；决策树 | 让多个测试用例通过 → 调试阈值边界与遗漏分支 |
| **五下** | 恒温箱或自动浇花控制；循环步进器 | 将系统维持在目标范围/单步验证累计 → 添加扰动、分析稳定性与能耗 |
| **六上** | 代码单步与变量表；二分搜索对战；Bug 调试台 | 逐步追踪并通过测试 → 预测复杂情况、修复边界 Bug |
| **六下** | AND/OR 开关电路；水箱反馈系统 | 通过真值表验证/稳定水位 → 搭组合逻辑、比较开环与闭环 |
| **七上** | 小型局域网拓扑；数据包逐跳演示；HTML 结构预览 | 合理连接与分配 IP/修正页面结构 → 诊断冲突、断线或标签嵌套错误 |
| **七下** | 传感器—执行器反馈；DFS 迷宫单步器 | 达到触发条件/观察回溯过程 → 处理传感器抖动、预测搜索路径 |
| **八上** | 凯撒密码转盘；DOM 节点探针；散列敏感性演示 | 完成加解密/定位节点/观察摘要变化 → 对比穷举与安全边界、分析完整性问题 |
| **八下** | KNN 平面分类器；卷积核观察台；神经元权重调节 | 观察近邻投票/滤波/调权重达标 → 比较噪声、核大小、偏置对结果的影响 |
